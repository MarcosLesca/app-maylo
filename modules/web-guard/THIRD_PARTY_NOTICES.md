# Third-party data in web-guard

`android/src/main/assets/web-guard/blocklist.txt` is a list of ad and tracker
domain names generated by `scripts/update-adblock-list.mjs` from the lists
below. Changes made: the lists were merged, lowercased, de-duplicated, local
names and IP addresses were dropped, subdomains of an already listed domain were
removed, and the hosts-file format was reduced to one domain per line.

Only permissively licensed lists are used. StevenBlack's unified `hosts` file is
not bundled as a whole because it also merges lists under non-commercial or
share-alike terms (MVPS hosts CC BY-NC-SA 4.0, Dan Pollock's hosts, yoyo.org,
KADhosts CC BY-SA 4.0).
